🍔 Swiggy Sales Analytics Dashboard
📌 Project Overview

This project focuses on analyzing Swiggy food delivery data to uncover meaningful business insights using Python, Excel, and Power BI. The dashboard provides an interactive view of sales performance, customer behavior, food category trends, and regional growth patterns.

The goal of this project is to transform raw data into actionable insights that can support business decision-making and improve operational performance.

📊 Dashboard Highlights
₹53M+ Total Sales
197K+ Orders Analyzed
4.34 Average Customer Rating
State-wise & City-wise Sales Analysis
Monthly, Weekly & Daily Sales Trends
Food Category Performance Analysis
Interactive Dashboard with Dynamic Filters
🛠 Tools & Technologies Used
Python → Data Cleaning & Transformation
Excel → Data Validation & Exploration
Power BI → Data Visualization & Dashboard Development
DAX → KPI Calculations & Measures
📈 Key Business Insights
Non-Veg category contributed the highest share of total sales
Bengaluru generated the highest revenue among all cities
Weekend sales were comparatively higher than weekdays
Customer ratings remained consistently strong across regions
Sales trends showed stable growth throughout the year
